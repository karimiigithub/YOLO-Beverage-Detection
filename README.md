# YOLO-Beverage-Detection

## Overview

This project is a real-time beverage recognition and price calculation system built using YOLO object detection. The system can detect and classify different canned soft drinks, including **Pepsi**, **7UP**, and **Yedigün**, directly from a live camera feed.

Once a product is detected, the system automatically retrieves its predefined price and calculates the total cost of all detected products in real time.

## Features

* Real-time object detection using YOLO
* Detection of Pepsi, 7UP, and Yedigün canned beverages
* Live camera integration
* Automatic product counting
* Instant total price calculation
* Bounding box visualization with product labels
* Lightweight and suitable for retail or smart checkout applications

## Technologies Used

* Python
* YOLO (You Only Look Once)
* OpenCV

## How It Works

1. The camera captures live video frames.
2. YOLO detects and classifies beverage cans.
3. Each detected product is matched with its predefined price.
4. The system sums the prices of all detected products.
5. The total price is displayed in real time on the screen.

## Use Cases

* Smart checkout systems
* Automated retail solutions
* Inventory monitoring
* Computer vision learning projects
* Object detection demonstrations
